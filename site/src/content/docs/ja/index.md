libtmux は tmux を制御する型付きライブラリで、Python、TypeScript、Rust、Go、
Java、.NET、C++、Swift の実装があります。ドキュメントはすべての実装で
一つのサイトを共有しています。

## 翻訳済みのページ

- [コンセプト](/concepts/)

翻訳されていないページには、英語の原文と翻訳を始めるためのリンクが表示されます。

どのページが翻訳済みで、どのページがまだかは[翻訳の進捗](/translations/)に
一覧があります。

## API リファレンスは翻訳しません

各実装の API リファレンスはソースコードのドキュメンテーションコメントから
生成されるため、翻訳の対象外です。バージョンごとに再生成されるものを翻訳
し続けることはできません。

- [実装ごとの一覧](/parity/)

英語版へはヘッダーの言語切り替えから移動できます。
