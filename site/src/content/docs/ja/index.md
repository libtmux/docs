libtmux は tmux を制御する型付きライブラリで、Python、TypeScript、Rust、Go、
Java、.NET、C++、Swift の八つの実装があります。ドキュメントはすべての実装で
一つのサイトを共有しています。

## 翻訳済みのページ

- [コンセプト](/concepts/)

翻訳されていないページも `/ja/` 以下で開けます。まだ翻訳がないことを伝える
ページが表示され、英語の原文へのリンクと、翻訳を始めるためのリンクが並び
ます。英語の本文をそのまま置くことはしません。URL は解決しても中身は英語
のままになり、検索索引にも `lang="ja"` として入ってしまうためです。

どのページが翻訳済みで、どのページがまだかは[翻訳の進捗](/translations/)に
一覧があります。

## API リファレンスは翻訳しません

各実装の API リファレンスはソースコードのドキュメンテーションコメントから
生成されるため、翻訳の対象外です。バージョンごとに再生成されるものを翻訳
し続けることはできません。

- [実装ごとの一覧](/parity/)

英語版へはヘッダーの言語切り替えから移動できます。ここからリンクしないのは、
このファイル内のリンクがすべて現在の言語を基準に組み立てられるためで、
`/en/` と書いても `/ja/en/` になってしまいます。
