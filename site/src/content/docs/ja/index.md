libtmux は tmux を制御する型付きライブラリで、Python、TypeScript、Rust、Go、
Java、.NET、C++、Swift の八つの実装があります。ドキュメントはすべての実装で
一つのサイトを共有しています。

## 翻訳済みのページ

- [コンセプト](/ja/concepts/)

翻訳されていないページは、この `/ja/` 以下には存在しません。英語版へ直接
移動してください。存在しない翻訳のかわりに英語をそのまま置くと、URL は
解決しても中身は英語のままになり、検索索引にも `lang="ja"` として入って
しまうためです。

## API リファレンスは翻訳しません

各実装の API リファレンスはソースコードのドキュメンテーションコメントから
生成されるため、翻訳の対象外です。バージョンごとに再生成されるものを翻訳
し続けることはできません。
