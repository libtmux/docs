Load `libtmux/workspace` to validate and plan workspace data, then apply it
through an explicit client. The `libtmux/workspace/cli` system provides the
command entry point. Both systems use the native core library.

The [workspace guide](../source-guide/) covers configuration, cleanup,
conflicts, and partial outcomes. The declarations below come from the same
source revision as the guide.
