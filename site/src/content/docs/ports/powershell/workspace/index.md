`LibTmux.Workspace` provides PowerShell commands for reading, validating,
planning and applying workspace configuration. The module uses `LibTmux`
for tmux objects and operations.

Install the module with the commands below, then follow the
[workspace guide](./source-guide/) to inspect a plan before applying it.
The [command reference](./reference/) lists every exported workspace command
and its parameter sets.

The [PowerShell Gallery package](https://www.powershellgallery.com/packages/LibTmux.Workspace)
also provides Azure Automation and manual download options. Manual downloads
require you to install the package dependencies separately.
